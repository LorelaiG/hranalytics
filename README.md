This project analyzes HR data to uncover workforce trends, employee attrition patterns, job satisfaction levels, and demographic insights. 
Using Microsoft SQL Server, I performed data exploration, KPI calculations, and business-focused queries to validate key metrics. 

The cleaned dataset was then visualized in Power BI through an interactive dashboard featuring employee headcount, attrition rate, department-level analysis, age-group distributions, job satisfaction ratings, and education-based attrition insights. 
The project demonstrates end-to-end data analysis, from SQL-based data validation to dashboard development and business intelligence reporting.
